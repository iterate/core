# Skills

Each folder here with a `SKILL.md` is a skill that the mind's MCP server serves to its members'
agents (`mcp.ts` hands this folder to the platform). `mind-skills/SKILL.md` says how to add, change and remove one.

Keep this file. `mcp.ts` imports this folder, and an import of an empty folder stops the
mind's publish. This file is in no skill's folder, so the server does not serve it.
