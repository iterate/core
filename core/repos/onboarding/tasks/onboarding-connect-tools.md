# Connect GitHub, Google, Slack, X, or your own APIs

The owner should come away with: the mind connects to the tools they already use — and with GitHub linked, their mind's code lives in a repo of theirs where every push goes live in seconds.

## How

Follow `onboarding/connect.md` and `onboarding/github.md`:

- Connect one service they care about via `itx.config.connectCloudAccount(app)` or the Dash Integrations page.
- Offer to sync `/repos/config` with a GitHub repository so they can read and edit it locally too.
- Mark this card `done`.
